# YouTube Deskargau

A Windows desktop downloader with a lightweight browser-based interface for downloading YouTube audio and video, editing media metadata, and managing embedded video subtitles.

> The application interface is currently in Spanish. Its main sections are **“Descargar MP3”** (Download MP3), **“Descargar vídeo”** (Download video), and **“Editar metadatos”** (Edit metadata).

## Features

- Download audio as MP3.
- Download video as MP4 when a compatible MP4 format is available.
- Embed common source metadata and cover artwork where supported.
- Download available video subtitles separately and attempt to embed them in MP4 without re-encoding audio/video streams.
- Edit supported MP3 metadata and embedded MP4 subtitle text (SRT/VTT).
- Open the interface in a dedicated Microsoft Edge or Google Chrome app window when a supported browser is found.
- Persist the dark/light theme preference; other download form settings are not intended to persist between launches.
- Keep a portable runtime under `app/runtime/`, generated by the setup script.

## Requirements

- Windows. The launcher and clipboard integration use Windows-specific features.
- An internet connection for the first-time portable setup and for YouTube downloads.
- Microsoft Edge or Google Chrome is recommended. The application can fall back to the system browser if neither supported executable is found.

The `app/prepare_portable.cmd` setup script downloads the configured portable Python runtime, Python packages (`yt-dlp`, Pillow, and Mutagen), Deno, and FFmpeg. Versions and download URLs are defined in that script.

## Installation and first launch

1. Download or clone this repository, keeping the root launcher and the `app/` folder in the same directory.
2. Open the `app` folder and run **`prepare_portable.cmd`**. Allow it to finish and confirm that its final checks pass. This step needs an internet connection.
3. Return to the repository root and double-click **`YouTube Deskargau.vbs`**.
4. Use the Spanish UI sections to download audio/video or edit metadata and embedded subtitles.

**Important:** `prepare_portable.cmd` rebuilds the `app/runtime/` directory. Do not run it while the application is open; any existing runtime in that directory will be removed and recreated. Do not rename `app/` unless you also update the paths in the VBS launcher.

## Usage

### Download MP3 — “Descargar MP3”

Paste one or more YouTube URLs, choose or provide an output name, and start the download. Finished audio files are saved in `Audios/`.

### Download video — “Descargar vídeo”

Paste one or more YouTube URLs and choose the available quality options. Subtitles are requested separately on a best-effort basis; a subtitle request failure should not stop an otherwise successful media download. Finished video files are saved in `Videos/`.

### Edit metadata — “Editar metadatos”

Select a media file in the editor. MP3 metadata fields can be edited, and MP4 subtitle text can be reviewed or replaced using SRT/VTT text. Subtitle stream support depends on the input file and FFmpeg capabilities.

## Troubleshooting

- **The launcher says setup is incomplete:** open `app/prepare_portable.cmd`, run it, and wait for the final verification step.
- **The app does not open:** check `app/gui_app.log` if it exists. Verify that `app/runtime/python/pythonw.exe`, the Deno executable, and FFmpeg are present.
- **No app-style browser window opens:** install or update Microsoft Edge or Google Chrome. The system browser may be used as a fallback.
- **Subtitles are missing:** the source may not expose subtitles, the subtitle request may have been throttled, or the selected subtitle format may not be embeddable. Subtitle embedding is best-effort.
- **YouTube changes break downloads:** update `yt-dlp` through the portable setup/runtime workflow and retry.

## Development notes

- The application entry point is `app/gui_app.py`.
- The front-end is `app/ui/index.html` and communicates with a local-only HTTP server bound to `127.0.0.1`.
- Portable dependencies and setup logic are maintained in `app/prepare_portable.cmd`.
- The console-based helper programs and menu are retained in `download_mp3.py`, `download_video.py`, `edit_metadata.py`, and `menu.py`, although the primary interface is the GUI.
- Do not commit generated runtime files, downloaded media, logs, or personal configuration files. The repository `.gitignore` excludes the common generated paths.
